## 产品方向

- 宠物档案、数字身份卡、成长故事、疫苗与健康记录。
- 日历待办、提醒、养宠账单与多宠费用分摊。
- 有来源和适用范围的养宠与营养知识。
- 宠物朋友圈、附近的喵/汪、好友关系与宠友群聊。
- 场景化丰富 UI，轻动效与可关闭的触觉反馈，避免以表格和打卡为主的首页。
- 宠物定位区分手机散步路线与兼容定位器回传位置；社交附近发现不开放实时定位。
- 后续评估家庭会员与宠物用品商城。
